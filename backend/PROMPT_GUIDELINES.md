# 📝 راهنمای ساختاردهی درخواست‌ها برای عملکرد بهینه

## 🎯 مقدمه
این سند راهنمای نحوه ارائه درخواست‌ها به AI برای دستیابی به بهترین نتایج در توسعه پروژه Sedi است.

---

## ✅ ویژگی‌های یک پرامپت موثر

### 1️⃣ **وضوح و مشخص بودن هدف**
**❌ بد:**
```
فایل prompts.py را بهتر کن
```

**✅ خوب:**
```
در فایل backend/app/core/conversation/prompts.py، system prompt را بهبود بده تا:
- GPT به سوالات کاربر پاسخ دهد (نه فقط greeting)
- از تکرار پاسخ‌های مشابه جلوگیری کند
- context و conversation history را درست درک کند
```

---

### 2️⃣ **ارائه Context کافی**
**❌ بد:**
```
مشکل در frontend است
```

**✅ خوب:**
```
در frontend/lib/features/chat/state/chat_controller.dart، مشکل این است که:
- user_id از backend دریافت می‌شود اما در درخواست بعدی ارسال نمی‌شود
- این باعث می‌شود هر بار کاربر جدید ایجاد شود و memory از بین برود
- باید user_id را در SharedPreferences ذخیره کنی و در هر درخواست ارسال کنی
```

### قالب 2: تغییر در چند فایل مرتبط
```
**هدف:** [توضیح کوتاه هدف]

1. [فایل 1] - [نقش آن]
2. [فایل 2] - [نقش آن]
3. [فایل 3] - [نقش آن]

**تغییرات در هر فایل:**
- **فایل 1:** [تغییرات]
- **فایل 2:** [تغییرات]
- **فایل 3:** [تغییرات]

**جریان کار:**
1. [مرحله 1]
2. [مرحله 2]
3. [مرحله 3]

**اولویت:** [بالا/متوسط/پایین]
```

**مثال:**
```
**هدف:** رفع مشکل user_id که در frontend ذخیره نمی‌شود

**فایل‌های مرتبط:**
1. frontend/lib/features/chat/chat_service.dart - ارسال user_id
2. frontend/lib/features/chat/state/chat_controller.dart - ذخیره user_id
3. frontend/lib/core/storage/storage_service.dart - سرویس ذخیره‌سازی

**تغییرات در هر فایل:**
- **chat_service.dart:** اطمینان از ارسال user_id در هر درخواست
- **chat_controller.dart:** ذخیره user_id در SharedPreferences بعد از دریافت از backend
- **storage_service.dart:** اگر وجود ندارد، ایجاد کن با متد saveUserId() و getUserId()

**جریان کار:**
1. ابتدا storage_service.dart را بررسی/ایجاد کن
2. سپس chat_controller.dart را تغییر بده برای ذخیره user_id
3. در نهایت chat_service.dart را بررسی کن که user_id را ارسال می‌کند

**اولویت:** بالا
```

## 🎯 نکات مهم برای عملکرد بهتر

### ✅ کارهایی که باید انجام دهی:

1. **قبل از درخواست تغییرات بزرگ:**
   - ابتدا از من بخواه که فایل را بررسی کنم
   - سپس تغییرات را مرحله به مرحله درخواست کن

2. **برای درخواست‌های پیچیده:**
   - ابتدا یک todo list ایجاد کن
   - سپس هر مرحله را جداگانه درخواست کن

3. **برای debugging:**
   - خطای دقیق را بده (اگر وجود دارد)
   - رفتار مورد انتظار را توضیح بده
   - رفتار فعلی را توضیح بده

4. **برای refactoring:**
   - مشخص کن که کدام بخش‌ها را می‌خواهی تغییر دهی
   - مشخص کن که کدام بخش‌ها را نباید دست بزنی

---

### ❌ کارهایی که نباید انجام دهی:

1. **درخواست‌های مبهم:**
   - "کد را بهتر کن" ❌
   - "مشکل را حل کن" ❌

2. **درخواست‌های بدون context:**
   - "این فایل را تغییر بده" ❌ (بدون توضیح مشکل)

3. **درخواست‌های خیلی بزرگ:**
   - "کل پروژه را بازنویسی کن" ❌
   - بهتر است به بخش‌های کوچک‌تر تقسیم کنی

## 📞 مثال درخواست کامل

```
**هدف:** بهبود system prompt برای پاسخ به سوالات کاربر و جلوگیری از تکرار

**فایل:** backend/app/core/conversation/prompts.py

**مشکل فعلی:**
- GPT فقط greeting می‌دهد و به سوالات کاربر پاسخ نمی‌دهد
- پاسخ‌ها تکراری هستند (مثلاً همیشه "سلام! چطور می‌تونم کمکت کنم؟")

**تغییرات مورد نیاز:**
1. در _build_system_prompt()، بعد از دستورات greeting، دستورات زیر را اضافه کن:
   - "اگر کاربر سوالی پرسید، باید به آن پاسخ دهی. سوالات را نادیده نگیر."
   - "از تکرار پاسخ‌های مشابه در conversation history جلوگیری کن. همیشه پاسخ جدید و مرتبط بده."
   - "از context و memory_facts برای شخصی‌سازی پاسخ استفاده کن."

2. در _build_user_prompt()، اطمینان حاصل کن که:
   - user_message حتماً به GPT ارسال می‌شود
   - conversation history شامل می‌شود (حداقل 5 پیام آخر)

3. در generate_response()، بررسی کن که:
   - context به درستی به _build_user_prompt() پاس داده می‌شود
   - user_message در context وجود دارد

**محدودیت‌ها:**
- ساختار response را تغییر نده (باید dict با کلیدهای 'response' و 'metadata' باشد)
- فقط محتوای prompt را تغییر بده، نه ساختار کد
- از async/await استفاده کن (نه threading)

**اولویت:** بالا

**بعد از تغییر:**
- بررسی کن که syntax errors نداشته باشد
- بررسی کن که imports درست باشند
- اگر مشکلی دیدی، قبل از اجرا به من بگو
```
